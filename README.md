# Statistics for Machine Learning 📊

A structured learning repository covering **Statistics from fundamentals to advanced concepts for Machine Learning**. It explores the mathematical principles behind data analysis, statistical inference, probability, model evaluation, and data-driven decision-making.

The goal is to understand how statistical concepts explain datasets, support algorithm selection, and help build reliable Machine Learning models.

## 📚 Topics Covered

### 1. Mathematical Foundations
- Basic algebra and mathematical notation
- Sets, functions, and summations
- Exponents, logarithms, and equations
- Vectors and matrices fundamentals
- Limits, derivatives, and gradients
- Mathematical notation used in statistics and ML

### 2. Descriptive Statistics
- Population and sample
- Types of data and measurement scales
- Mean, median, and mode
- Range, variance, and standard deviation
- Quartiles, percentiles, and interquartile range (IQR)
- Five-number summary
- Skewness and kurtosis
- Frequency distributions
- Tables, histograms, box plots, and scatter plots

### 3. Probability Fundamentals
- Random experiments, outcomes, and events
- Sample spaces and event operations
- Probability rules and axioms
- Conditional probability
- Independent and mutually exclusive events
- Law of total probability
- Bayes' theorem
- Counting principles, permutations, and combinations

### 4. Random Variables & Probability Distributions
- Discrete and continuous random variables
- Probability mass functions (PMFs)
- Probability density functions (PDFs)
- Cumulative distribution functions (CDFs)
- Expected value and variance
- Bernoulli and binomial distributions
- Geometric and Poisson distributions
- Uniform, normal, exponential, and gamma distributions
- Student's t, chi-square, and F distributions
- Central Limit Theorem (CLT)

### 5. Sampling & Sampling Distributions
- Population parameters and sample statistics
- Simple random, stratified, and cluster sampling
- Sampling bias and selection bias
- Sampling distributions
- Standard error
- Law of Large Numbers
- Central Limit Theorem applications
- Bootstrap sampling and resampling methods

### 6. Inferential Statistics
- Point estimation
- Estimators and their properties
- Bias, consistency, and efficiency
- Maximum Likelihood Estimation (MLE)
- Method of Moments
- Confidence intervals
- Margin of error
- Statistical significance and practical significance

### 7. Hypothesis Testing
- Null and alternative hypotheses
- Significance levels and p-values
- Type I and Type II errors
- Statistical power
- One-tailed and two-tailed tests
- Z-tests and t-tests
- Paired and independent-samples t-tests
- Chi-square tests
- Analysis of Variance (ANOVA)
- Multiple testing and correction methods
- Effect sizes and their interpretation

### 8. Correlation & Regression
- Covariance and correlation
- Pearson and Spearman correlation
- Correlation versus causation
- Simple and multiple linear regression
- Regression assumptions
- Least-squares estimation
- Residual analysis
- Coefficient of determination (\(R^2\))
- Multicollinearity and variance inflation factor (VIF)
- Logistic regression fundamentals

### 9. Bayesian Statistics
- Prior, likelihood, and posterior distributions
- Bayes' theorem in statistical inference
- Bayesian updating
- Maximum A Posteriori (MAP) estimation
- Bayesian versus frequentist approaches
- Credible intervals
- Bayesian decision-making fundamentals

### 10. Statistical Relationships & Multivariate Analysis
- Confounding variables
- Simpson's paradox
- Partial correlation
- Covariance matrices
- Multivariate distributions
- Multivariate normal distribution
- Principal Component Analysis (PCA)
- Dimensionality reduction and variance explained

### 11. Information Theory for ML
- Entropy
- Conditional entropy
- Cross-entropy
- Kullback–Leibler (KL) divergence
- Mutual information
- Information gain
- Gini impurity and decision-tree splitting

### 12. Statistics for Model Evaluation
- Confusion matrices
- Accuracy, precision, recall, and specificity
- Sensitivity and false-positive rates
- ROC curves and Area Under the Curve (AUC)
- Precision–Recall curves
- Calibration and predicted probabilities
- Confidence intervals for model metrics
- Cross-validation and uncertainty in performance estimates
- Class imbalance and sampling considerations

### 13. Experimental Design & A/B Testing
- Controlled experiments
- Randomization and control groups
- Treatment and control effects
- A/B testing
- Sample-size and power calculations
- Confounding and experimental bias
- Multiple comparisons
- Causal inference fundamentals

### 14. Statistical Computing with Python
- NumPy for numerical computation
- Pandas for data analysis
- SciPy for statistical tests and distributions
- Matplotlib and Seaborn for visualization
- Statsmodels for statistical modeling
- Scikit-learn for ML evaluation
- Simulation and Monte Carlo methods
- Reproducible statistical experiments

**Language:** Python

## 🎯 Learning Objectives

- Develop a strong statistical foundation for Machine Learning.
- Understand uncertainty, variability, and probability distributions.
- Choose appropriate statistical tests and interpret their results.
- Understand regression, estimation, and statistical inference.

- Evaluate ML models using statistically sound methods.
- Translate mathematical theory into practical Python implementations.

## ▶️ Getting Started

Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
cd statistics-for-ml
```

Create and activate a virtual environment on Windows:

```bash
python -m venv .venv
.venv\Scripts\activate
```

Install the libraries you need:

```bash
pip install numpy pandas scipy matplotlib seaborn statsmodels scikit-learn jupyter
```

Launch Jupyter Notebook:

```bash
jupyter notebook
```
